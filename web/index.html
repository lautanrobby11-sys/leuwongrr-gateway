Quickstart

Create a key on the member dashboard, then call it like any OpenAI endpoint.

curl 
curl https://api.leuwongrr.cloud/v1/chat/completions \
  -H "authorization: Bearer $LWRR_KEY" \
  -H "content-type: application/json" \
  -d '{"model":"lwrr-text","messages":[{"role":"user","content":"ping"}]}'
python · openai sdk 
from openai import OpenAI

client = OpenAI(
    base_url="https://api.leuwongrr.cloud/v1",
    api_key="lwrr_live_…",
)

reply = client.chat.completions.create(
    model="lwrr-text",
    messages=[{"role": "user", "content": "ping"}],
)
print(reply.choices[0].message.content)

Anthropic-style clients use POST /v1/messages with the same bearer token. Streaming is server-sent events on every surface.
